# Haris Rusnanda - Personal Portfolio

Personal portfolio website of **Haris Rusnanda, S.Kom**, an Informatics graduate interested in **IoT Engineering, IT Support, and Software Development**.

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS v4
- Lucide Icons

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
```

## Portfolio Data

Personal information and portfolio content are managed in [`src/data/portfolioData.js`](src/data/portfolioData.js).

This includes profile, education, experience, projects, skills, achievements, and contact information.

## Focus

- IoT & Embedded Systems
- IT Support & Networking
- Web & Software Development
